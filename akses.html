Wajib Ubah URL API di File HTML!

Agar web katalog bisa terhubung ke database Google Sheets Anda sendiri, Anda WAJIB mencari baris variabel SCRIPT URL di dalam file HTML dan menggantinya dengan URL Web App Google Apps Script milik Anda yang sudah di-deploy.

const SCRIPT_URL = 'URL WEB APP GOOGLE APPS SCRIPT ANDA DISINI';

Aturan Lisensi (Reseller Right)

Wajib Dipatuhi Oleh Semua Reseller:

  • Jual Kembali dengan mengikuti harga pusat (Harga Promo min. Rp 37.000).
  • Bisa digunakan sebagai Jasa Pembuatan Web Katalog untuk Klien Anda.
  • Hak Setara: Anda dan Pembeli Anda mempunyai hak jual yang sama (Unlimited Resell).
  • Bebas Modifikasi Frontend: Diperbolehkan mengganti warna, teks, logo, atau merombak desain file index.html.
  • Dilarang Keras: Rebranding nama produk iMersAFFLINK menjadi brand buatan Anda sendiri jika menjual source code-nya.
  • Dilarang Keras: Mengubah atau mengotak-atik file backend Code.gs. Merubah file ini akan menggugurkan hak free update.
Panduan Visual UI

Rekomendasi Ukuran Gambar Katalog:

Banner Promo (Carousel)

  • Dimensi Ideal: 1200 x 400 px atau 800 x 300 px.
  • Format Rasio: Landscape memanjang agar pas di layar Desktop maupun Mobile.

Gambar Thumbnail Produk

  • Format Rasio: Square 1:1 (Kotak).
  • Dimensi Ideal: 500 x 500 px.
  • Pastikan gambar telah dikompres via TinyPNG agar loading web tetap kencang!
