Panduan Instalasi & Penggunaan

Selamat datang di dokumentasi iMersAFFLINK! Halaman ini akan memandu Anda secara bertahap dari cara setup database gratis menggunakan Google Sheets, meng-online-kan web menggunakan Vercel, hingga membedah fitur-fitur di dalam Dashboard Admin.

Sebelum Memulai

Pastikan Anda sudah mendownload file Source Code HTML (.zip) dari halaman akses dan sudah mengekstraknya di komputer/laptop Anda. Anda juga membutuhkan akun Gmail dan akun Vercel.com (gratis).

1

Setup Database Google Sheets

Web ini tidak membutuhkan database MySQL (phpMyAdmin) yang mahal. Kita murni menggunakan Google Sheets sebagai tempat menampung produk.

  • Buka tautan Template Google Sheets yang sudah disediakan di Halaman Akses.
  • Pastikan Anda sudah login ke akun Google (Gmail) Anda.
  • Klik menu File > lalu pilih Buat Salinan (Make a copy).
  • Beri nama file sesuka Anda (Misal: Database Affiliate Saya), lalu klik tombol Buat Salinan.

Penting: Jangan pernah mengubah nama Header (Baris 1 yang tebal) atau nama Sheet di bagian bawah (seperti Produk, Kategori, Pengaturan). Mengubahnya akan menyebabkan dashboard error karena script tidak dapat membaca kolom.

2

Deploy Google Apps Script

Setelah database di-copy, kita perlu mengaktifkan "mesin" (API) yang akan menghubungkan Google Sheets Anda ke Web Katalog.

  • Di file Google Sheets hasil copy-an Anda, klik menu Ekstensi yang ada di atas, lalu pilih Apps Script.
  • Sebuah tab baru akan terbuka. Biarkan proses loading selesai. *Kode backend sudah tertanam di dalamnya secara otomatis.*
  • Perhatikan tombol biru di pojok kanan atas bertuliskan Terapkan (Deploy). Klik tombol tersebut, lalu pilih Deployment Baru (New Deployment).
  • Pada icon gear (pengaturan) pilih tipe Aplikasi Web (Web App).
  • Isi deskripsi (bebas, misal: "V1").
  • PENTING: Pada bagian Yang memiliki akses (Who has access), Anda WAJIB memilih Siapa saja (Anyone). Jika tidak, data produk Anda tidak akan muncul di website.
  • Klik tombol Terapkan (Deploy).
  • (Jika diminta Otorisasi/Akses Akun, klik Izinkan > Lanjutkan > Buka URL (Tingkat Lanjut) / Allow > Advanced > Go to Untitled Project).
  • Setelah sukses, akan muncul sebuah URL Web App (URL Aplikasi Web). Salin (Copy) URL yang panjang tersebut. Kita akan memakainya di Langkah 3.
3

Edit URL API di Frontend HTML

Sekarang buka folder Source Code (hasil ekstrak ZIP) yang ada di komputer Anda. Anda membutuhkan aplikasi text editor ringan seperti Notepad, Sublime Text, atau VS Code.

  1. Buka file index.html menggunakan text editor.
  2. Tekan Ctrl + F (atau Cmd + F di Mac) lalu cari tulisan const SCRIPT_URL.
  3. Ganti URL *dummy* bawaan kami dengan URL Web App hasil Salinan Anda dari Langkah 2. Pastikan URL tersebut tetap berada di dalam tanda kutip tunggal '...'.
  4. Save file (Ctrl + S).
  5. Ulangi langkah yang sama untuk file admin.html. Buka filenya, cari variabel yang sama, lalu timpa URL-nya. Save.

Contoh Kode yang Benar:

const SCRIPT_URL = 'https://script.google.com/macros/s/AKfycbwXYZ123ABC_Contoh_URL_Anda_Panjang_Banget/exec';
4

Deploy Web ke Vercel (Go Live)

File HTML Anda sudah siap! Saatnya kita *online*-kan agar bisa diakses seluruh dunia 24 jam nonstop tanpa perlu sewa hosting bulanan. Kita akan menggunakan Vercel (Gratis).

  • Buka website Vercel.com dan buat akun (bisa *Sign up* menggunakan Gmail atau GitHub).
  • Setelah masuk ke Dashboard Vercel, buat project baru (Add New > Project).
  • Ada 2 cara upload file:
    • Cara 1 (Termudah): Tarik (Drag & Drop) 1 folder utuh Source Code iMersAFFLINK Anda ke area halaman Vercel yang disediakan.
    • Cara 2 (Via GitHub): Jika Anda punya akun GitHub, push folder Anda ke repo GitHub, lalu *import* repo tersebut dari dalam Vercel.
  • Beri nama *Project Name* Anda (misal: katalog-shopee-saya), lalu klik tombol Deploy.
  • Tunggu proses 1-2 menit hingga muncul animasi kembang api. Selamat! Website Katalog Anda sudah LIVE!

Note: Vercel akan memberikan domain gratis berakhiran .vercel.app (contoh: katalog-shopee-saya.vercel.app). Jika Anda punya domain custom berbayar (.com / .id), Anda bisa menambahkannya nanti di menu Settings > Domains pada Vercel.

Panduan Fitur Dashboard Admin

Untuk masuk ke panel admin, buka URL web Anda dan tambahkan /admin.html di belakangnya. (Contoh: katalog-saya.vercel.app/admin.html).
PIN Login Default: 123456 (Anda bisa mengubah PIN ini di database Google Sheets pada tab "Pengaturan").

Beranda (Overview)

Menampilkan ringkasan total jumlah produk Anda, kategori yang aktif, serta banner promo yang sedang tayang.

Manajemen Produk

Menu paling utama. Disini Anda bisa Tambah, Edit, atau Hapus produk. Anda diminta memasukkan Nama, Harga (Opsional), Kategori, Link URL Affiliate tujuan, dan Link URL Gambar Produk.

Manajemen Kategori

Mengatur Tab Filter (seperti: "Gadget", "Fashion", "Ecourse"). Buatlah kategori yang spesifik agar pembeli mudah menyaring (filter) katalog produk Anda.

Banner Slider

Upload gambar (masukkan URL gambar/Imgur) untuk ditampilkan sebagai carousel promosi memanjang di bagian paling atas halaman depan web Anda.

Pengaturan Web

Fitur canggih untuk mengubah Nama Web, Warna Tema Utama (Gradient), Teks Custom Tombol (misal defaultnya "Beli" bisa diganti "Order di Shopee"), serta merubah PIN Login Dashboard Anda.
